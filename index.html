Asisten Administrasi PPDS

Membantu dan memudahkan PPDS dalam otomatisasi manajemen rekam medis (EMR) dan laporan operan jaga via Telegram & GDocs, sehingga Anda bisa fokus pada pasien.

💥 The Chaos

❌

Waktu habis untuk urusan administrasi, mengganggu waktu pelayanan pasien dan kegiatan ilmiah.

❌

Risiko human error saat input data (EMR/GDocs) akibat lelah atau mengantuk pasca-jaga.

❌

Beban kerja berlebih karena rasio jumlah pasien yang sangat banyak ditangani setiap harinya.

✨ The Solution

✅

Otomatisasi input SOAP dan pembaruan EMR/Gdocs hanya dengan chat via Telegram.

✅

Human-in-the-Loop: Semua aksi (resep, order lab, update EMR) memerlukan approval konfirmasi Anda.

✅

Tarik dan *update* data pasien *real-time* kapan saja tanpa perlu membuka laptop.

Core Capabilities

📲

Telegram-to-EMR Sync

Input identitas dan SOAP via Telegram. Data otomatis terhubung ke Google Docs (operan) dan draf EMR rumah sakit.

🔬

Auto-Update & Orders

Order Lab/Radiologi dan dapatkan notifikasi otomatis ke Telegram saat hasil pasien keluar untuk langsung di-update.

🛡️

Smart Approval System

Asisten akan menyusun draf resep, konsul sejawat, dan pesan ke DPJP yang wajib Anda setujui sebelum dikirim.
